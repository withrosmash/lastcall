## Template (unchanged from round 2)

- Glow: radial gradient in the accent, 22% to 0
- Disc: #141414 dark, #FFFFFF light, r225
- Ring: accent at 35%, r206, 3 units
- Highlight arc: #FFFFFF at 6% dark, #0A2419 at 4% light
- Glyph: Lucide, 24 grid, 1.5 stroke, round caps and joins, scaled 9.5

## Accents

Dark: mint #7EE0C0, pink #F06C9B, amber #EF9F27, forest #35A26F.
Light (provisional, darkened for contrast on white until the round 2 light table is confirmed): mint #23866A, pink #C23F72, amber #A8660A, forest #21764F.

When the three mode glow colours arrive, only the accent hex changes per file.

## Rename

First Night is now First Adventure. Name only; the art stays.

## Metadata

Files saved from this project pick up a C2PA `<metadata>` block and an `xmlns:c2pa` attribute. Strip both (or run svgo) before shipping.
