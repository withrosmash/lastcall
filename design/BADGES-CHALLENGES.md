# Challenge badges — addendum for Claude Design

Five more badges, same spec as `BADGES.md` (SVG, 512 canvas, 88% safe zone,
1.5-unit stroke on a 24 grid, earned/locked states, one accent from mint
`#7EE0C0` / pink `#F06C9B` / amber `#EF9F27` / forest `#35A26F`).

These cover the new Challenges feature: the app offers a dare, the user marks
it done. Nothing in the challenge set involves drinking, so these should read
as playful and social rather than boozy.

| Slug | Name | Criteria | Accent | Category |
|---|---|---|---|---|
| `first-dare` | First Dare | Complete your first challenge | mint | Firsts |
| `game-on` | Game On | Three challenges in one night | pink | Funny |
| `no-notes` | No Notes | Five challenges in one night | pink | Funny |
| `ringleader` | Ringleader | 25 challenges all-time | amber | Aspirational |
| `chaos-agent` 🔒 | Chaos Agent | Ten challenges in one night | pink | Funny |

Until the art lands the app draws a placeholder ring with the badge's initials,
so the feature works and the swap is a drop-in of five files.
