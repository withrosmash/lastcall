8d App icon, splash and notification icon

Three directions, each shown as a launcher icon with Android’s circle and rounded-square masks, at launcher size and at 48 px, plus the one-colour notification icon at true size (24 px) and enlarged. Your face or the default face

The launcher icon and the system splash can’t be the user’s own face. Both platforms read them from a fixed file in the app, before any of the app’s code runs. So A uses a default face: the same character, in the brand colours. The hand-off is where it becomes yours. The system splash shows the default face in the icon circle. The app’s first frame then draws the user’s own avatar in the same spot, at the same size, and it waves. The notification’s large image and the recap are drawn by the app, so they use the user’s face too.
