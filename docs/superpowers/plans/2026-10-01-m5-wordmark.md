# M5: The Leit wordmark — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Claude Design's "Norr" wordmark replaces the typed "Leit" wherever the brand shows: the start screen, the first-launch walkthrough, the splash hand-off and both share cards. The store gets a lockup and a feature graphic.

**Architecture:**
- **One source:** `js/wordmark.js` holds the wordmark as four rectilinear paths (from `design/round3/wordmark/leit-wordmark-mono-currentcolor.svg`, translated to a 0,0 origin, view 190.25 × 52). Everything draws from it.
- **App:** inline SVG via `wordmarkSvg(height)`, using `currentColor`.
- **Cards:** canvas `Path2D` via `drawWordmark(g, x, y, height, color, align)`, with the photo card's text halo.
- **Store images:** `scripts/icons.mjs` fills the same shapes as rectangles.

**Spec:** `design/BRIEF-ROUND-3.md` §1 and the round 3 delivery README:
- cap height 52, stroke 4.5;
- clear space of one cap height;
- minimum cap height 8 px;
- mint `#7EE0C0` at the card foot on dark.

## Global Constraints

- **In-app heights (cap height = total height):** start screen 15 px, walkthrough 15 px, hand-off 18 px.
- **Card heights:** 30 px on both cards. The route card is left-aligned where the text sat; the photo card is right-aligned bottom right.
- **Colours:**
  - route card: `T.mark` (mint on dark, `#0B6E55` on light);
  - photo card: mint, with the photo text theme's halo;
  - start screen: `--mint-dim`, as the eyebrow had;
  - hand-off: `--mint-dim`.
- **Accessibility:** the SVG has `role="img"` and `aria-label="Leit"`.
- New `js/wordmark.js` goes in SHELL, and CACHE bumps to `lastcall-v32`.
- **Store outputs:** `design/round3/store-lockup.png` (1024 × 300: icon plus wordmark on black) and `design/round3/feature-graphic.png` (1024 × 500, Google Play's feature graphic: forest bloom, icon, wordmark, tagline area left empty because text rendering isn't in the script).

## Review Focus

1. **Clear space:** the card wordmark keeps one cap height (30 px) from the stats above it, and from the edges by the existing margins. (browser)
2. **Photo card text themes** Light, Halo and Dark all keep the wordmark readable. (browser)
3. **Video layers:** the wordmark layer still exports, cropped tight. (browser)
4. **Very small renders:** nothing draws it below an 8 px cap. (test)
5. **The paths match the delivered SVG exactly,** with no hand-retyped coordinates. (test reads the SVG file)
